# 真实阅读验收

适用：扫描书净化、批量转换，或用户在自动检查通过后仍反馈字号、目录、图片及排版问题。复用现有质量门和缓存，不启动额外调度器。

1. 从原用户要求和输入内容确定目标。对照真实目录、首中末正文及至少一个容易出错的页面；混合输入每种结构选一个代表样本，不能用文字书通过代表扫描书通过。
2. 检查目录条目是否对应真实章节、跳转是否正确；“只有一个正文入口”或条数相同不代表满足多级目录要求。检查可调字号、中文段落、标题层级、页眉页脚残留及内容完整性。
3. 有效 OCR 缓存可复用时先复用。仅在原任务已指定的书籍与内容范围内应用“不再 OCR”“删除全部图片”；新扫描件、图表教材和有内容价值的图片必须重新判断。特定书籍错字映射不可全局套用。
4. 先完成最小代表样本，修正已知失败，再批量产出。相关自动门通过后，按现有设备检查表抽查字号、连续翻页、目录跳转、图片/表格及脚注；设备不可用则保留 `DEVICE_VISUAL_PENDING`，不得冒充 `PW2_PASS`。
5. 验收记录关联成品 SHA-256、输入类型、检查入口、结果、待验项和回滚位置。只有 exact 命中、字节完全一致且条件未变，才能复用该成品已有真机批准。
6. 不为了验收自动覆盖 Kindle 旧书或删除 `.sdr` 阅读状态。原有固定目标授权、备份及回滚边界保持有效；新字节替换按当前授权核对。

依据：2026-09-02 扫描书任务中，格式检查与复制一致后仍出现阅读质量返工；本条沉淀的是验收方法，不认证旧书或当前设备状态。检查强度按实际风险，不为本 reference 的文字改动运行整书转换。
